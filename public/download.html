下载 LexiPair-unsigned.ipa 打开 Web 版

全能签安装流程

1Safari 下载

点击下载按钮，在文件 App 中确认文件名是 LexiPair-unsigned.ipa。

2导入全能签

打开全能签，选择导入 IPA，把刚下载的文件加入应用列表。

3签名安装

选择证书和描述文件，完成签名后点安装到桌面。

4信任证书

进入设置，信任开发者描述文件，再打开 LexiPair。

同步与 AI

iOS 端需要能访问同一个 LexiPair API 地址。局域网测试时手机和电脑要在同一网络；正式使用请把 API 部署到公网并重新打包 IPA。
